# PretExpress

Application interne de gestion des demandes de pret personnel - Caisse Horizon.

Version 2.4. Maintenue par l'equipe Credit-TI jusqu'en 2022.

## Demarrer

Prerequis : Java 17+, Maven 3.9+

    mvn spring-boot:run

Puis ouvrir http://localhost:8080

Ou : ouvrir le depot dans GitHub Codespaces (tout est deja configure).
